⚡ Donate your CPU

Your idle cores power live games. Your donor name is your 8Chess account: no anonymous donors, no strangers.

1
Run one command
curl -sSL http://localhost:8080/worker.py | python3 - --server http://localhost:8080
Requires Python 3.8+. The script prints a one-click approval link — approve it in your browser (step 2) and your account becomes the live donor name.
2
Approve the script in your browser

The website opens automatically via the link the script prints. You can also paste a worker code here to approve it manually.

3
Prefer a token instead?

Skip browser approval by passing a personal token:

Download worker.py python3 worker.py --server … --token <your-token>
